
Asteroid Entry Dynamics
=======================

Asteroid Entry Dynamics is a scientific Python project for the numerical
and differentiable simulation of asteroid atmospheric entry.

The project aims to provide a modular framework for physical modelling,
numerical integration, energy deposition analysis and computational
performance evaluation.

The documentation describes the physical assumptions, numerical
methods, software interfaces and verification procedures associated
with the simulation framework.
